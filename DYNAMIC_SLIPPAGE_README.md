# Dynamic Slippage Implementation

## Overview

This implementation introduces a **dynamic, self-adapting slippage model** that replaces the fixed slippage rate with a volatility-responsive system. The model uses ATR (Average True Range) as the primary metric to calculate slippage that reflects real-time market conditions.

## Core Algorithm

```
Volatility Ratio = Current ATR / ATR Moving Average
Dynamic Slippage = base_rate × Volatility Ratio  
Final Slippage = clamp(Dynamic Slippage, min_slippage, max_slippage)
```

## Configuration

### Enable Dynamic Slippage
In `experiment_config.yaml`, the slippage configuration now supports both modes:

```yaml
evaluation:
  simulation_env:
    slippage:
      mode: 'relative_volatility'  # or 'fixed' for backward compatibility
      base_rate: 0.0001           # 0.01% - minimum slippage in calm markets
      atr_ma_window: 50           # lookback for "normal" volatility baseline
      min_slippage: 0.00005       # 0.005% - floor cap
      max_slippage: 0.002         # 0.2% - ceiling cap
```

### Fixed Mode (Backward Compatibility)
```yaml
slippage:
  mode: 'fixed'
  fixed_rate: 0.0005  # 0.05% constant slippage
```

## Data Requirements

The dynamic slippage model requires these data columns (automatically generated by the enhanced data pipeline):

- `ATR_14`: Current market volatility (already exists)
- `ATR_14_MA_50`: 50-period moving average of ATR (newly added)

## Behavior Examples

| Market Condition | ATR | ATR-MA | Ratio | Base Rate | Final Slippage |
|------------------|-----|--------|-------|-----------|----------------|
| Normal | 0.10 | 0.10 | 1.0 | 0.01% | **0.010%** |
| High Volatility | 0.20 | 0.10 | 2.0 | 0.01% | **0.020%** |
| Low Volatility | 0.05 | 0.10 | 0.5 | 0.01% | **0.005%** |
| Extreme High | 0.50 | 0.10 | 5.0 | 0.01% | **0.200%** (capped) |
| Extreme Low | 0.001 | 0.10 | 0.01 | 0.01% | **0.005%** (floored) |
